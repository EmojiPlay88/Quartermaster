# Teams: Former Side Ids and Alliances (B8) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sides can list the ids they had in older packs (`FormerIds`): a loaded game, its undo history, its seats and the pack's own references read as the listing side. Sides can share an alliance (`AllianceId`): allies see what each other sees and act on each other's units and in each other's phases, through one widened held set; ownership and seats are unchanged.

**Architecture:** Rules gains the two `SideDef` fields, `SideFacts` (former-id map, `Held` = the one place a player's held set is formed, `MapReferences`) and validator checks. Core gains `FormerSides` (state and command translation) and `GameSession.MapSides` (history translated, state replayed). Render applies the translation when a game is loaded or the pack changes, and calls `SideFacts.Held` at the five places a player's sides become a held set. Desktop gains the Sides-box editors; docs.

**Tech Stack:** C# .NET 10, Avalonia (Desktop), xUnit.

**Spec:** `docs/superpowers/specs/2026-11-26-b8-teams-design.md`

## Global Constraints

Read `.superpowers/sdd/2026-11-26-b8-teams/global-constraints.md` (git-ignored; same folder as the ledger) before each task. It holds the invariants and **every exact validator, diagnostic, Workbench and dialog string**; use them verbatim. In short:
- Public repo: invented data only (Riverland: Northern League `north`, Southern Compact `south`, Hill Clans `hills`; alliance `Upriver Pact`). No content from any published game anywhere (code, tests, docs, packs). Expression identifiers use letters, digits and `_` only.
- Old packs keep bytes + SHA-256, `CurrentFormat` 4. Old saves keep bytes; a loaded game is translated in memory only, and only when it names a former id. Every new pack member is omitted when null; blank text becomes null on load.
- Additive API only: init properties on `SideDef`; new classes `SideFacts`, `FormerSides`; new members `GameSession.MapSides`, `ModuleSession.PlayerSides`, `PhaseEdit.SetSideAlliance/SetSideFormerIds/MergeSide`; no changed signatures.
- **One place forms a held set**: `SideFacts.Held` at the five call sites of the spec; no rule gets its own ally test; ownership and seats unchanged.
- Hidden information: a side outside the alliance sees and may do exactly what it could before; guests see hidden values masked; the host decides and checks every guest intent with the alliance-widened set.
- Packs without alliances or former ids pay nothing (same set instance, no scan, no replay).
- `-c Release`, one test project at a time, headless only, never stash/push, repo-local identity, `Co-Authored-By: Claude <Model> 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Old packs and saves keep bytes**: a hand-written pre-B8 `pack.json` literal (three sides with unit filters, a phase with reactors, an ask entry, a holder, a map owner, an alert and a victory condition with sides) loads and saves byte-equal with a constant SHA-256 (Task 1 `B8_absent_fields_keep_bytes`); a save loaded with a pack that has former ids the save does not use keeps every object and saves byte-equal (Task 3 `Load_without_former_ids_keeps_save_bytes`).
2. **One held set**: `grep -rn "PlayerView.For(\|new PieceAccess(\|SetViewSides(\|_exec.Execute(\|ApplySnapshot(" src` — every player-side set reaching a rule passes through `SideFacts.Held` at the five sites; no `AllianceId`/`Alliance(` read outside `SideFacts`, the validator and the Workbench (Task 4).
3. **No leak**: a side outside the alliance sees nothing more in hot-seat, online (snapshot and Preview) and turn files; a guest's intent on a non-ally's unit is still refused with the old text (Task 4).
4. **History consistency**: after translation, undo/redo, step back and a save-then-load all keep the listing ids and the load replays without a rebase notice (Task 2 `Mapped_session_save_replays_without_rebase`, Task 3).
5. **Nothing for packs without the features**: `SideFacts.Held` returns the same instance; `MapSides` is not called (Tasks 1, 3, 4 perf/identity tests).
